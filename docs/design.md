# 知序视觉方案

产品面向卡在算法思路上的个人学习者。视觉中心是「从题目走到解法」的路径，不使用装饰性数据仪表盘。

色彩：纸面 #F7F9FC、边栏 #EEF3F7、墨色 #203344、青绿 #147D70、浅薄荷 #E5F2EE、辅助蓝 #5E7A9B。
字体：正文优先 Microsoft YaHei / PingFang SC；英文标题 Georgia；代码 Consolas / monospace。中文左对齐，讲解行宽限制，正文行高 1.8。
布局：侧栏 + 顶部状态区 + 任务内容。首页非等宽网格：左侧输入和推荐题，右侧学习状态。做题页按题目 / 引导 / 代码三栏组织。
区别：没有虚构学习统计；空状态表达下一步；提示级别就是学习路径。青绿用于动作和已完成的阶段，复杂度标签采用低饱和蓝灰。
交互：键盘焦点可见、弹窗 Escape 关闭、减少动态效果、手机单栏、深色模式。截图复核首页与工作台后再交付。

优化模块延续原有颜色和字体：在中央工作区切换「思路引导 / 解法优化」，代码编辑器保留在右侧。先以并排表格比较原解法与建议目标的时间、空间复杂度，再列出瓶颈和顺序明确的优化步骤。分析与生成代码分成两次动作。报告基于具体代码快照，采用和恢复代码都有来源；不把更短、虚构跑分或阅读提示数量当成性能提升。

## 水墨视觉更新

主题是算法书斋：宣纸承载题目、墨色承载思考、朱砂用于品牌印记。底色 #F7F6F0，浓墨 #29372F，松绿 #365A49，淡洗 #E8EDE5，朱砂 #AC483C，灰墨 #657368。标题用系统楷体 / 宋体，正文和代码沿用现有字体。

布局沿用现有工作台；山水作为首页和背景的视觉中心，题目 / 讲解 / 编辑器保持清晰的纸面层次。原先的平涂大面改成远山墨晕、纸纹和淡竹；避免把每个卡片都装饰成山水画。手机端缩减背景范围，深色模式对应夜墨。

交互效果回应用户操作：任意位置按下时出现几圈淡墨水波，包括空白、正文、编辑器及按钮；键盘激活控件也能触发。约 1.2 秒后移除，减少动态效果时关闭动画，效果层不拦截点击。艺术资源使用本地 SVG，无额外图片请求和画布动画循环。

## 毛笔与可调整布局

延续宣纸、松绿、灰墨和朱砂配色，正文及代码字体不变。桌面光标使用 32px 本地 SVG 毛笔，笔尖为点击热点，边界调整仍显示横向 / 纵向拖动光标。

布局以用户的阅读空间为中心：侧栏和主内容、题目 / 引导 / 编辑器、首页输入 / 学习足迹、设置偏好 / 说明可横向调整；引导内容 / 追问区、代码 / 操作区可纵向调整。首页卡片也可拖动底部边界改变高度。拖动边界使用细墨线与短手柄，悬停或操作时清晰显示；最小尺寸保证控件可用，布局自动保存到本机浏览器。双击边界恢复默认，方向键微调。手机保留单栏及标签切换，避免将三栏压进窄屏。

## 专注做题与明确的动态反馈

做题时隐藏侧栏、全局状态栏和题目工具栏，桌面三栏铺满视口；返回、题目标题、笔记和掌握操作收进题目栏的紧凑菜单。手机保留三个区域切换标签。颜色与字体延续算法书斋，调整边界仍可拖动。

Windows 系统关闭动画会导致之前的水波完全隐藏。现在提供动态 / 跟随系统 / 关闭三个明确选项；根据用户明确要求默认动态，动态选择覆盖系统的减少动画设置。水波更明显、缓慢扩散后消失，仍不拦截输入。

DeepSeek 连接明确区分官方按量计费 API 和网页版转接。网页版由用户复制题目上下文、在官方页面发送，再导入回复；界面不将手动转接显示成自动调用，也不声称永久免费 API。转接保留进度和代码快照，导入成功后才推进提示或保存优化报告。

## 算法动态演示

放在引导区第三个标签「算法演示」，保持全屏三栏。演示是可修改数据的独立经典例子，明确标出条件；不自动声称已经解析任意粘贴题目。先支持有序两数之和、闭区间二分、括号栈和爬楼梯 DP。

沿用宣纸 #F7F6F0、浓墨 #29372F、松绿 #365A49、朱砂 #AC483C，辅以蓝灰 #587B8B 与淡金 #A78238 区分左右指针、中点与依赖。正文沿用现有字体，数字和核心代码使用 Consolas。颜色同时配合 L / R / mid 标签、下标及状态文字，不单靠颜色传达状态。

布局自上而下：选择与输入 → 当前状态画布 → 一步说明与变量 → 时间轴与播放控件 → 可展开的 C++ / Python 核心代码。动画表现实际的指针位移、栈元素出入和 DP 依赖流动；每一步有确定的不可变快照，回退完全还原该步。暂停、单步、倍速、拖动时间轴和重新开始随时可用，默认暂停。页面隐藏、修改数据或切换算法时暂停；减少动态效果时关闭过渡，仍可单步读状态。每题保存已应用的输入和当前位置，刷新恢复到暂停状态。

验收重点：输入范围、排序条件、空数组、重复值、负数、无解、单元素、括号不匹配及未闭合、DP 基础状态。用独立枚举 / 递归结果核对生成器，验证每帧变量和对应核心代码，再检查桌面、窄栏、手机、夜墨和播放生命周期。演示算法复杂度与保存动画快照的开销分别说明。


## 本次自主完善的模块

备份卡片沿用设置页纸面、细边与松绿动作，预览先显示实际新增 / 相同记录，再让用户挑选恢复；不使用虚构完成率。

复习页采用三项实际统计与题目列表。回想练习先显示题目，主动展开个人笔记，四档自评直接写明下一次间隔。仅“忘了”不使用警告红，以降低不必要的挫败感。夜墨与手机沿用原来的留白和字体。

笔记弹窗增加写作 / 预览标签和可填写提纲；导出、字数、保存状态位于内容下方。自动保存失败与版本冲突在原位置解释，其他窗口草稿提供可展开的文本预览，避免占据正常解题空间。

动画新增滑动窗口、BFS 与无序哈希两数之和。绿色表示保留状态，淡金表示当前检查，蓝灰表示最优窗口 / 另一端，朱砂只用于重复匹配异常提示；位置、下标、距离与文字共同表达状态。所有图从确定快照读取，动态部分表现真实指针和队列位置，静态截图在过渡完成后检查。


连接失败使用简洁的接线图标、独立的纸面错误信息和一个重试动作，保持山水背景，避免空白页或假零统计。复习数据未读到时用横线表示未知，刷新失败保留上次读取的安排并说明它可能过期。
